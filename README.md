# 💼 Personal Portfolio Website

🚀 **Live Demo**: [ghanshyam2959.github.io/portfolio](https://ghanshyam2959.github.io/portfolio)

This is my personal portfolio website built using **React.js**, **Vite**, and **Tailwind CSS**. It showcases my skills, projects, experience, education, and provides downloadable documents like my resume and certificates.

---

## 📌 Sections

- **Home**: Intro with name and title
- **About**: Summary of who I am
- **Projects**: Featured projects with links
- **Skills**: Technologies I work with
- **Experience**: Internship and work experience
- **Education**: Academic background
- **Documents**: Java certificate, internship letter & resume
- **Services**: What I can offer
- **Contact**: Get in touch with me

---

## 🛠️ Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Icons**: React Icons
- **Deployment**: GitHub Pages
